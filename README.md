# Climate Hackathon 2026

A simple **model router** that chooses which LLM (or other model) to use with a **carbon emissions / environmental impact** lens.

The goal is to route each request to a model that is good enough for the task while keeping energy use and estimated emissions as low as practical.

## Why this exists

Not every prompt needs the largest, most expensive, or most energy-hungry model. This project explores routing that balances:

- **Task fit** — pick a model that can actually do the job
- **Environmental cost** — prefer lower-impact options when they are sufficient
- **Practical constraints** — latency, quality, and availability still matter
